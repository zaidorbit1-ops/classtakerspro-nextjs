## IMAGE OPTIMIZATION TECHNICAL GUIDE

### Current Problems:
1. Many images labeled just "Aliment" (decorative SVGs - no alt needed)
2. Actual content images have generic alt text
3. Images not compressed (impacting page speed)

### Solution:
**For every image, ask:**
- "Is this content or decorative?"
  - If decorative → alt=""
  - If content → Add descriptive alt text with keywords

**Alt Text Formula:**
`[What it shows] + [Why it matters] + [Optional keyword]`

Example:
- ❌ Bad: "image"
- ❌ Bad: "student"
- ✅ Good: "Student using laptop for online class with coffee and notes on desk"
- ✅ Better: "Online class tutor helping student complete assignment at home"
